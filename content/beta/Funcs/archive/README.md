# Archived FunCS Beta Mockups

This folder holds older exploration and design artifacts for the interactive
FunCS beta prototype. They remain in the repository for reference, but they are
not the active lesson/chapter/book flow.

The current beta flow lives one level up in `content/beta/Funcs/` and uses the
shared lesson kit:

- `Ch1 Data Memory Sequence.html`
- `Ch1 Boolean Expressions Sequence.html`
- `Ch1 Lesson Sequence.html`
- `Ch1 Roadmap.html`
- `Ch2 Numeric Data Memory Sequence.html`
- `Ch2 3 Sequence.html`
- `Ch2 4 Sequence.html`
- `Ch3 Array Memory Sequence.html`
- `Ch4 Linked Node Chain Sequence.html`
- `Ch4 Linked Traversal Sequence.html`
- `lesson-kit/concept-lesson-kit.jsx`
- `tb-cycle-components.jsx`

Archived assets in this folder include the original design canvas, wireframes,
approach comparison components, sketch files, and uploaded design images.
